# Learning Path: Making the Most of Claude Pro

The plan for learning what AI can do using the Claude apps (web, desktop, mobile)
and Claude Code. No API key or coding knowledge needed.
Each step is a small hands-on project with a write-up in [`projects/`](projects/).

Some features depend on your plan and settings and change over time. If a menu
or button looks different from what's described here, ask Claude where it went.

---

## Phase 1 – How AI actually behaves
*Learn by experimenting in ordinary chats.*

| # | Project | You'll learn |
|---|---------|--------------|
| 02 | **How AI "thinks"**: six quick chat experiments | Wording changes answers; the model has no built-in memory; it can confidently make things up; it has a knowledge cutoff; giving it room to think helps |
| 03 | **AI with your own stuff**: upload a PDF, photo and spreadsheet | Claude only knows what's in the conversation (its "context"); how to check its work against the source |

## Phase 2 – Claude's toolkit
*The features that turn a chatbot into a working tool.*

| # | Project | You'll learn |
|---|---------|--------------|
| 04 | **Projects**: build a personal "AI learning coach" | Custom instructions and knowledge files, the same idea as a "system prompt" |
| 05 | **Artifacts**: make an interactive quiz or mini-app in chat | AI can build working things, not just write text |
| 06 | **Research**: investigate a topic with web search | How AI finds and cites sources, and how to verify them |
| 07 | **Connectors**: let Claude use your Gmail, Calendar or Drive | AI using "tools" and your real data; privacy and what to allow |

## Phase 3 – AI that takes action (Claude Code)
*Agents: AI that plans, works in steps and uses tools on its own.*

| # | Project | You'll learn |
|---|---------|--------------|
| 08 | **Build a small website** together | Directing an AI agent; reviewing its work; iterating |
| 09 | **Automate something**: a scheduled weekly task | AI working on its own while you're away |

## Phase 4 – Big picture
| # | Project | You'll learn |
|---|---------|--------------|
| 10 | **Limits and judgment**: when to trust AI and when not to | Bias, errors, privacy, and good habits |
| 01 | **Back to the API** ([Hello, AI](projects/01-hello-ai/)) | How your own programs can use AI, once you want to build apps |
